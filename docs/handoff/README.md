# Predaje između faza

Svaka faza iz [TODO.md](../../TODO.md) počinje jednom predajom `Fxx-<tema>.md`. Predaja
je samostalna: nova sesija je pročita i radi bez drugog konteksta. Na kraju faze
nastaje predaja za sljedeću, a faza se u TODO-u označi ✅.

Predaja sadrži: cilj faze, polazno stanje s putovima do koda, zadatke redom, što je
„gotovo”, što treba od korisnika, i čega se ne dirati.
